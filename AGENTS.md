# AGENTS.md — инструкции для ИИ-агентов

Сначала прочитай `README.md`.

- **Считается только маржа** (OLX quick-sale − цена покупки). Не добавляй доставку/растаможку без просьбы владельца.
- Порог маржи — настройка `/margin` (D1 `kv`, ключ `margin`), по умолчанию 80 €.
- **Не обходить защиту сайтов.** OLX доступен серверам Cloudflare без обхода; если начнёт отвечать 403/капчей — сообщить владельцу, не подключать прокси/headless.
- Бот отвечает только `TELEGRAM_CHAT_ID`. Не коммитить секреты (`.env`, `.run_key`, `.webhook_secret`).
- Лимит CPU 10 мс на запрос: разбор строками/регулярками, OLX — 3 страницы, кэш 6 ч.
- Отрицания в немецком тексте («keine Kratzer», «nicht defekt») обрабатывает `findUnnegated` — новые слова добавляй в списки `BLOCKERS/MINUSES/PLUSES/SCAM` в `src/iphone.js`.
- Проверка: `for f in src/*.js; do node --check $f; done`, deploy, затем `/run?key=…&url=…&price=…` на 3–5 реальных объявлениях.
